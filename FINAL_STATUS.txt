💻 USAGE

Basic:
  python generate_schema_ddl.py -H HOST -d DB -u USER -s SCHEMA

With output file:
  python generate_schema_ddl.py -H HOST -d DB -u USER -s SCHEMA -o output.sql

With password:
  export PGPASSWORD=secret
  python generate_schema_ddl.py -H HOST -d DB -u USER -s SCHEMA

NOTE: Use -H (capital H) for host, not -h (which is reserved for --help)
